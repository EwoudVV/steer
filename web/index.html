steer

Tracks the time you spend working with AI coding agents. The time the agent runs by itself doesn't count, only what you do around it: writing prompts, reading what it did, testing and fixing things. Made for Hack Club's AI time tracking bounty.

See it on real work: a live page, which updates while duck works, and a review page, what a reviewer opens when a project gets submitted.

Live tracking

Install steer once and it tracks Claude Code, Codex, OpenCode, Copilot, Cursor and Freebuff while you work, also when T3 Code runs Claude Code or Codex for you. Your page at steer.duck.hackclub.app/u/your-name updates as you go.

Paste this into a terminal. It tells you what it's going to change and asks before doing anything.

Mac and Linux (Terminal):

curl -fsSL https://steer.duck.hackclub.app/install.sh | sh

Windows (PowerShell):

irm https://steer.duck.hackclub.app/install.ps1 | iex

Prompt text never leaves your computer, only counts like how many words it had and whether it said what happened when you tested something. The code is at github.com/EwoudVV/steer. If something seems off, run steer doctor. To undo everything: steer uninstall

Submitting a project

When you ship a project, run steer submit in its folder. It freezes the project's hours into a page with its own link, and prints a line to paste into the hours field when you submit. The page has the hours, a written justification, checks, every day and every session, and your commits linked on GitHub, so a reviewer can check the hours without having to ask you anything. It never changes after that, even if you keep working.

Or check your old Claude Code logs

Claude Code keeps them in a hidden folder:

  • Mac and Linux: ~/.claude/projects
  • Windows: %USERPROFILE%\.claude\projects

In the folder picker, press Cmd+Shift+G on a Mac and paste the path, or paste it into the address bar on Windows. To drag it from Finder instead, press Cmd+Shift+. to show hidden folders.
