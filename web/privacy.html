steer / privacy

steer tracks the time you spend working with AI coding tools. This page lists everything it sends and keeps, for the steer app and for the steer browser extension. The code for all of it is at github.com/EwoudVV/steer, so you can check.

What never leaves your computer

  • The text of your prompts, and the AI's answers. steer reads a prompt to work out a few counts, like how many words it had, and then drops it.
  • Your code, file names and file contents.
  • Anything outside the AI tools and projects you use. steer doesn't look at your screen, other apps, your browsing or what you type anywhere else. The one thing it reads from the whole computer is how long since the keyboard or mouse was touched, listed below.

What gets sent

Each thing you do with an AI tool becomes one event, sent to steer's server. A prompt event has only these fields:

id, session, project, via (which tool), time, words, chars, images, specific, observation, generic, repeat

The last four are counts and yes/no flags worked out from the prompt on your computer, like how many file names or error messages it mentioned. When you change code or commit in a repo you used AI in, steer sends project, time, count of files changed or project, time, commit hash. The project is the name of the git repo or folder you were in. Each batch also says what time your computer thinks it is, so a wrong clock can be corrected.

If you turn on check-ins, each answer sends which of the three buttons you picked and when.

steer also collects a few signs of what you're doing, so it can count your time from what you actually do instead of guessing from gaps. They don't count toward anything yet:

  • wait: Claude Code showed you a permission prompt. Only that it did, nothing about the tool or the command.
  • focus: a ChatGPT or Claude tab came to the front, or stopped being there.
  • copy and typing: you copied something out of a ChatGPT or Claude tab, or started typing your next message there. Never the text.
  • away, back and here: from your computer's idle timer, only within an hour of using an AI tool. Away when nobody touched the keyboard or mouse for 2 minutes, back when someone does again (with how long they were gone), and here every 5 minutes while someone's there. The idle timer is one number of seconds. It has no app names and nothing about what you typed.
  • editor: from steer's VS Code and Cursor extension, a stretch of time you were typing, clicking or scrolling in a project's files while the editor was in front. Only the project's name, when it started, how many seconds it lasted, and which editor. Only for projects you used an AI tool in within 2 hours of it. Never file names, code or what you typed.

Prompts also say which permission mode Claude Code or Codex was in (like "default" or "never"), and tool events say how long the tool ran.

The browser extension

The steer extension only runs on chatgpt.com and claude.ai. When you send a message there, it counts the message inside your browser, the same way the app counts a prompt, and notices when the answer is done. It also notices when the tab comes to the front or leaves it, copying, and when you start typing a message, as above. It hands only those counts to the steer app on your computer, which sends them like any other event, with via chatgpt or claude-ai. The message text and the answers stay in your browser. The extension doesn't send anything to any server itself, and the only permission it asks Chrome for is talking to the steer app on your computer.

The VS Code and Cursor extension

steer setup adds a small steer extension to VS Code and Cursor if it finds them. It notes when you type, click or scroll in a file that's in your project folder while the editor window is in front, and writes the folder and the times to a file in ~/.steer on your computer. An agent editing files doesn't count, since that changes files without any typing or clicking. The steer app reads that file and sends only the project's name and the times, as above. The folder's path stays on your computer. The extension never reads your code, file names or what you type, and doesn't send anything anywhere itself. steer uninstall takes it out, or you can remove it in the editor.

What steer keeps

  • Your account: your steer name and, if you sign in with Hack Club, your Slack id, whether your Hack Club account is verified and whether it's eligible for YSWS programs. No email or address.
  • Your events, as listed above, with when the server got them.
  • Projects you submit for review, and what reviewers decided about them.

IP addresses are only used in memory to stop too many requests, and aren't saved or logged. The only cookies are one for a few minutes while you sign in, and one that keeps reviewers signed in. No ads, no analytics, no trackers. Nothing is sold or shared, beyond your page being public.

What's public

Your page at steer.duck.hackclub.app/u/your-name is public, like a Hackatime profile: your projects, sessions and hours, and the events behind them. Hack Club programs and reviewers can look up your hours by your Slack id to check a project you shipped.

Deleting your data

steer uninstall stops all tracking and removes steer from your computer. To have your account and events deleted from the server, message duck on the Hack Club Slack or open an issue on GitHub, and it gets deleted.
