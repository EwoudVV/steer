steer / your old Claude Code logs

Claude Code keeps a log of every session, so steer can work out the time you already spent from those, without installing anything. It only knows what's in the logs, so it misses testing and coding by hand that live tracking would catch.

The logs are in a hidden folder:

  • Mac and Linux: ~/.claude/projects
  • Windows: %USERPROFILE%\.claude\projects

In the folder picker, press Cmd+Shift+G on a Mac and paste the path, or paste it into the address bar on Windows. To drag it from Finder instead, press Cmd+Shift+. to show hidden folders.
